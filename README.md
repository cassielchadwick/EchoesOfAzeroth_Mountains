# Echoes of Azeroth: Quel'Thalas

`EchoesOfAzeroth_QuelThalas` is a content plugin for `EchoesOfAzeroth`.

Adds support for Vanilla Dun Morogh and Loch Modan zone music.

## Requires

- `EchoesOfAzeroth`

This plugin will not load correctly on its own.

## Included music packs

The plugin includes packs for:

- "Mountains" Walk Music, Day and Night

It also includes a default list of zone assignments for Dun Morogh and Loch Modan.

## How to use it

1. Install `EchoesOfAzeroth`
2. Install this plugin
3. Open `/eoa options`
4. Enable the plugin in `Plugins`
5. Adjust mappings in `Zone Mapping` if desired

## Notes

- The plugin only provides content data
- Playback logic, profiles, custom zones, and custom packs are handled by the core addon
- Pack selection and plugin enable/disable are managed from the `EchoesOfAzeroth` UI

## Community profiles

`EchoesOfAzeroth` is meant to grow as a community addon.

If you build a profile that feels especially polished, immersive, or lore-accurate, please share it. Great community profiles can help refine the addon over time, and an especially strong configuration may be adopted as an official default or recommended setup in the future.
